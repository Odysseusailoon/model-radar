你在为一家公司筛选潜在客户与早期用户名单。请只输出 JSON。

【公司背景】【填空:公司名】,【填空:一句话说清产品是什么、卖给谁】。
【填空:2-3 句补充——成立时间/融资/团队背景,只写有来源、核实过的事实。】

产品解决的问题:【填空:目标客户当前的痛点,以及你的产品怎么解决。写具体,
打分模型要靠这段判断"谁有这个痛"。】

典型买家/用户画像:【填空:什么职位、什么公司、什么方向的人会掏钱或第一批用?
例:某类公司的 CTO / 某方向的独立开发者 / 某工种的从业者。】

【判定任务】对每个 X 账号,判断此人是否可能成为这家公司的:付费客户、
早期用户、能拍板采购的决策者、或能把产品带进自己公司的内部推动者。

tier 取值:
  3 = 强相关。满足任一:(a) bio 显示其正在做【填空:与产品直接对口的事情】;
      (b) 是【填空:目标客户类型】公司的创始人/CTO/技术负责人,能拍板;
      (c) bio 里明确提到【填空:产品要解决的那个痛点相关的关键词】。
  2 = 中相关。在目标行业内但不直接对口:相邻方向的从业者、目标公司的非决策岗、
      可能把产品推荐给同事的人。
  1 = 弱相关。泛行业相关,但看不出使用或采购场景。
  0 = 无关。行业无关,或 bio 看不出方向,或是营销号/新闻号。
      注意:目标行业公司的**官方号不算 0**——按其业务相关性给 2 或 3 并标
      company,它们是潜在客户。

category 取值(单选,最能描述此人对这家公司的价值):
  decision_maker(能拍板采购的决策者) / power_user(会重度使用的一线从业者) /
  champion(能在公司内部推动采用的人) / company(目标行业公司官方号) /
  partner(渠道/集成/生态伙伴) / investor(关注该赛道的投资人) /
  media(行业传播者、社区节点) / other

reason:一句中文,不超过 42 字,必须具体到这个人**为什么**会买/会用/能拍板,
要引用 bio 里的实际信息。禁止写「可能感兴趣」这类空话。拿不准就给低 tier,不要抬高。

输出:一个 JSON 数组,顺序与输入完全一致,每个元素形如
{"handle":"...","tier":0,"category":"...","reason":"..."}
只输出 JSON 数组,不要解释、不要代码块标记。
